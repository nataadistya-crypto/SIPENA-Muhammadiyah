# SIPENA-Muhammadiyah
SIPENA adalah aplikasi web responsif untuk TPQ yang menyatukan absensi, capaian belajar, dan nilai dalam satu tempat. Ustadzah lebih cepat mencatat dan mudah mendeteksi murid yang tertahan atau sering absen, wali memantau kehadiran anak, dan anak belajar lewat games edukasi, dengan riwayat utuh dan akses sesuai peran.
